# NBA Criteria Calculation

A web-based academic project created to support the calculation and organization of criteria used in NBA accreditation documentation. The project brings form-based data entry into a web interface rather than relying entirely on scattered spreadsheet workflows.

## Technologies

- PHP
- HTML and CSS
- MySQL (database-backed web application components)

## Repository contents

The repository includes PHP form pages organized around accreditation criteria, including criterion-specific forms and supporting assets.

## Run locally

This is a PHP web project. To explore it locally:

1. Install a local PHP/MySQL development environment such as XAMPP.
2. Clone or download this repository into the web server's document directory.
3. Configure the database connection and create any required database tables based on the application code.
4. Start Apache and MySQL, then open the project through your local server.

The exact database schema and setup may need to be reconstructed from the source code; this repository does not currently provide a complete database export or verified one-click setup.

## Project context

Developed as an academic/group project to make NBA criteria-related calculations and data entry easier to manage. Review the source code and configure a local database before use.
